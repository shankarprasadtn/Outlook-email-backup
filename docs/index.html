Automate Your Outlook to SharePoint Attachments Pipeline

A modern Windows desktop application designed to monitor your Outlook folders, extract email attachments with custom subject or file keyword filters, rename them dynamically, and synchronize them directly to SharePoint or OneDrive.

Download App Source Code
OutlookSharePointSync.exe - Live Console

How It Works

The synchronization engine operates completely in the background or on manual triggers to copy your scanner files safely.

1

Monitor Folder

Scans a selected Outlook folder (e.g. "HP Scan") for unread emails on a schedule.

2

Apply Keywords

Matches subject lines or attachment filenames for "onboarding", "spare", or "replacement".

3

Intelligent Rename

Prefixes attachments with category and dates, e.g. spare_20260521_File.pdf.

4

SharePoint Sync

Copies files to the designated folders, marks the email as READ, and checks for duplicates.

Core Features

Built for speed, safety, and enterprise compliance with zero complex overhead.

📧

Dual Outlook Modes

Use local Outlook COM Automation (requires zero-config profile login) or head-less M365 Microsoft Graph API directly over Microsoft servers.

☁

Flexible Upload Sync

Save files directly into your local OneDrive Synced Library, or upload straight to the SharePoint Cloud API using secure MSAL PKCE OAuth.

📁

Dynamic Bifurcation

Automatically separates normal documents into onboarding paths while moving files containing spare or replacement to Spare 2026 subdirectories.

🕑

Interval Polling

Run the synchronization on a continuous thread from 1 to 60 minutes. Minimize the app directly to the Windows System Tray for quiet background operation.

🔍

Duplicate Verification

Performs a hash or filename lookup on the destination library before uploading, saving network bandwidth and avoiding file conflicts.

📄

Full Logging

View visual, color-coded consoles showing scanning success, download speeds, skipped duplicates, and detailed system error stack traces.

Download & Setup

Get started with the precompiled executable or run directly from the Python source code.

  • 1

    Download Executable

    Download the pre-compiled executable file OutlookSharePointSync.exe directly from this repository root folder or the Releases section.

    Direct Download (.EXE)
  • 2

    Launch and Configure

    Double-click the executable to launch. Navigate to the **Configuration** tab in the sidebar and configure your Outlook folders, Microsoft Graph site details, or local OneDrive folder paths.

  • 3

    Trigger Synchronization

    Click **Sync Now** on the main dashboard to verify your settings. The console log will display real-time progress details. After validating, set a background poll interval to automate it.

  • 1

    Clone the Repository

    Clone the code folder to your local machine using Git:

    git clone https://github.com/shankarprasadtn/Outlook-email-backup.git
  • 2

    Execute Batch Installer

    Run the run.bat file. This script automatically checks your system for Python 3, sets up a virtual environment (.venv), installs the dependencies from requirements.txt, and launches the application.

    run.bat
  • 3

    Compile into Executable

    If you make changes to the source files, you can recompile them back into a single Windows executable using the provided compile.bat batch script:

    compile.bat
